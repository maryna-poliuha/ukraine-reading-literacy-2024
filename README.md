# Читацька грамотність четвертокласників України (2024)

**Навчальний аналітичний проєкт | Data Analyst internship**

Досліджено зв'язок **навчальної тривожності** та **підтримки родини** з результатами читання четвертокласників України за відкритими знеособленими даними ЗЗМЯПО-2024.

**Головне дослідницьке питання:** за яких поєднань тривожності та підтримки родини учні частіше не досягають базового рівня читацької грамотності?

**Основні результати:** у вибірці з 3 602 записів зважена частка учнів передбазового рівня становить **17,72%**. У дев'яти групах за тривожністю та підтримкою родини частка коливається від **5,65%** до **25,18%**. Це описові зв'язки, а не доказ причинного впливу.
